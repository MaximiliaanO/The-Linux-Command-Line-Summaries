# Chapter 2: Navigation

## Basic commands:

| Command | Description                                    |
|---------|------------------------------------------------|
| pwd     | Print name of current working directory (path) |
| cd      | Change directory                               |
| ls      | List directory contents                        |

#### Some shortcuts:

| Shortcut      | Description                                                                                                               |
|---------------|---------------------------------------------------------------------------------------------------------------------------|
| cd -          | Changes the working directory to the previous working directory                                                           |
| cd ~user_name | Changes the working directory to the home directorhy of user_name. I.e. ~bob will change it to the home directory of bob. |
