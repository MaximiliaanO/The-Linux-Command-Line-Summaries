# Chapter 5: Working with commands

## What exactly are commands?

- An executable program
- A command built into the shell itself.
- A shell function.
- An alias.

## Identifying commands

- ```type``` *command*
- ```which``` *command* determines the exact location of an executable (multiple versions)
- ```help``` *command* for shell builtins
- ```executable --help``` many executables support this command
- ```man``` *program* shows the programs manual.
- ```apropos``` *searchterm* search the list of man pages based on a search term
- ```whatis``` One-line manual page description
- ```info``` Display a program's info entry hperlinked
